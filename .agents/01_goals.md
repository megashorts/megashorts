# MegaShorts 프로젝트 목표 및 요청사항

> 최종 업데이트: 2026-05-13

## 프로젝트 개요
- **서비스**: 세로형 영상 스트리밍 플랫폼 (MegaShorts)
- **기술 스택**: Next.js 15 + Prisma + Supabase(PostgreSQL) + Cloudflare(Stream/R2/Workers/D1) + Lucia Auth
- **배포**: Vercel
- **결제**: 토스페이먼츠(테스트모드), Paddle(이전 시도)
- **메일발송**: Resend
- **도메인**: megashorts.com / lullove.com

## 7가지 요청사항 요약

### 1️⃣ MCP 설치 (Vercel, Supabase, Cloudflare)
- AI 코딩 효율화를 위한 MCP 서버 설치
- **상태**: 분석 완료, 구현 문서 작성 완료

### 2️⃣ msworker 폴더 정리
- 사용되지 않는 워커 제거, 사용 중인 워커만 정돈
- 정리 후 개선사항 제안
- **상태**: 분석 완료, 구현 문서 작성 완료

### 3️⃣ 유료 컨텐츠 시청 권한 검사 최적화
- 현재 구현 분석 + KV/DO 활용 방안 제안
- 구독정보, 코인, 시청기록 각각의 최적 저장소 전략
- **상태**: 분석 완료, 구현 문서 작성 완료

### 4️⃣ 다국어(next-intl) + PWA 구현 가능성 분석
- 중국어, 한국어, 영어 3개 언어
- 세로형 UI 고정, 오토플레이, 프리뷰 다운로드, 전용 UI
- **상태**: 분석 완료, 구현 문서 작성 완료

### 5️⃣ 기타 플랫폼 개선사항 제안
- 인증, 스트리밍, 시청기록, 커스텀 로그 등
- **상태**: 분석 완료, 구현 문서 작성 완료

### 6️⃣ 결제 서비스 Stripe 추가 구현
- 토스페이먼츠와 동일한 기능을 Stripe로 구현
- 기본값: Stripe / 환경변수로 한국IP만 토스 사용 가능
- **상태**: 분석 완료, 구현 문서 작성 완료

### 7️⃣ 글로벌 성인인증 구현
- 한국방식이 아닌 자기신고방식(Self-declaration)
- 기존 adultauth 필드와 연동
- **상태**: 분석 완료, 구현 문서 작성 완료
