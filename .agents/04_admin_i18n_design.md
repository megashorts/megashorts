# 관리자 동적 콘텐츠 다국어 설계 정리본

> 최종 업데이트: 2026-05-22

## 상태
이 문서는 초기 설계 초안이 아니라, 현재 코드베이스에 반영된 운영 기준을 요약한 정리본입니다.
승인 대기/다음 작업 지시 문구는 제거했습니다.

## 현재 적용 기준

### 1) 데이터 모델 원칙
- 동적 콘텐츠의 다국어 데이터는 JSON 계열 필드(`titleI18n`, `contentI18n`)를 중심으로 운영합니다.
- 원문 필드(`title`, `content`)는 fallback의 최종 기준으로 유지합니다.

### 2) 표시 fallback 원칙
- 표시 우선순위: 선택 언어 -> 영어 -> 원문
- 번역 키 alias(`ko/kr`, `zh/cn`, `en`)를 허용하는 보정 로직을 적용합니다.

### 3) 관리자 정책
- `/admin/system`에서 콘텐츠 언어 노출 정책을 전환할 수 있습니다.
- 기본값은 전체 노출 + 선택 언어 우선 표시이며, 운영 상황에 따라 선택 언어 지원 콘텐츠만 노출 정책을 사용할 수 있습니다.

### 4) 관련 소스 위치
- 서버 유틸: `src/lib/content-language-server.ts`
- 클라이언트/공통 유틸: `src/lib/content-language.ts`
- 관리 설정 반영: `src/app/[locale]/(main)/admin/system`
- 아키텍처 기준 문서: `.agents/04_architecture.md`
